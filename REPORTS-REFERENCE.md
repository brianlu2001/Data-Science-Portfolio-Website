## ➕ **To Add New Reports:**

1. **Add file** to `public/reports/` folder in your GitHub repo
2. **Commit and push** changes
3. **Use URL format**: `/reports/Your-File-Name.pdf` or `/reports/Your-File-Name.html`

---

> **Note:** File names with spaces need to be URL-encoded when accessing, but the system handles this automatically.
